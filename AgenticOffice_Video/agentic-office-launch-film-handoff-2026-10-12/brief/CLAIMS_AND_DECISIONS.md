# Decisions carried forward / release gates

User feedback and team screenshots informed these decisions. Private chat screenshots and phone numbers are intentionally not copied; the useful creative decisions are summarized here.

| Topic | Keep / show | Avoid / still confirm |
| --- | --- | --- |
| Main proposition | Word, Excel, PowerPoint formats in one agentic, collaborative professional workspace | Not just a cross-document trick or generic AI chat; no complete Microsoft 365 replacement promise |
| Hook | Three work cards merge, a little breathing space between app names | No PDF-editing promotion; no rushed list; audience copy says work, not project |
| UI | Actual team-provided screenshot/prototype and new authentic recordings | No generative/repainted controls, invented result, fake clicks, or unsupported UI |
| Prompt to deck | One prompt uses memo + forecast; proposed presentation opens in the main UI | Existing source is prototype; real generation capture and shipping confirmation are required |
| Selective edits | Accept or reject individual proposed changes, without whole-document rewrite | Screenshot proves visible controls, not an accepted/rejected result; capture real action |
| Collaboration | Shared document, presence, changes, proposals | Prototype isn't release proof; confirm actual supported interaction |
| Cross-agent | Context sharing, coordinated handoff, proposed next change; human decides | No guaranteed autonomous completion/sending; confirm and record the actual handoff |
| Time saving | Less copying, less rework, less switching to separate AI chats | No fabricated minutes/percentages or competitive benchmark |
| Local files | Files stored on device; agent works inside workspace; no separate manual upload step | Local storage ≠ local inference. Keep “Cloud AI may process document content.” Product team must confirm exact data flow |
| Privacy tone | Subtle sense of continuity/control through local file tree and user review | No shield/cloud-blocked icon, “privacy solved,” “never uploaded,” “whole files never sent,” or “local-only AI” |
| Art direction | Plain stages, typography, graphics, truthful UI; reuse opening card language | No AI-generated people, photographic office/laptop shots, cluttered unrelated effects |
| Audio | Narration plus jazz-like groove, drum rolls, synchronized SFX | YouTube music rights are unknown. Inherited SFX licenses unresolved; OpenArt subscription isn't clearance |
| Workflow | New request: Claude + OpenArt; keep V11 Remotion baseline for continuity | Do not force earlier Remotion-only preference onto the new requested workflow; do not assume a quality ceiling of any framework |

## Public launch gates

Confirm all advertised features ship. Replace/label prototype sequences honestly. Obtain sanitized product recordings and official logo/CTA. Confirm privacy wording against architecture. Clear final VO/music/SFX/model-output usage rights. Check accessibility/readability and audio/video export. This folder is a production handoff, not a release authorization.

Only the intelligence comes from the cloud." The small print "The AI model receives only the text a task needs." is **pending owner confirmation**.
